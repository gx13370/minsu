📌 如何获取 iCal 链接？
Airbnb：登录 Airbnb → 房源 → 日历设置 → 导出日历 → 复制链接（每个房间一个链接）
Booking.com：登录 Extranet → 日历 → 导出日历 → 复制 iCal URL

💡 iCal 导出的预订只有日期信息，不含客人姓名和价格，同步后可手动补充。已同步的预订再次同步时会自动更新日期，不会重复创建。
